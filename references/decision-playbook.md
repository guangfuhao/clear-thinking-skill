# 清晰思考：决策工作台

这份参考文件用于需要完整展开时。它把清晰思考框架整理为可复用的工作表；它不是对所有场景的唯一正确流程。

## A. 决策卡

```text
决定：
为什么现在要决定：
时间范围/截止时间：
目标（最多 3 个）：
硬约束：
不可接受的结果：
可控因素：
可影响因素：
不可控因素：
```

## B. 默认反应扫描

| 可能接管的本能 | 常见信号 | 校正问题 |
| --- | --- | --- |
| 情绪 | 想立刻反击、证明、报复或逃离 | 如果去掉评价和面子，我会怎么选？ |
| 自负 | 觉得坏事不会发生、低估能力边界 | 什么证据会证明我错？谁更懂这件事？ |
| 合群 | “大家都这么做”“不这样会显得奇怪” | 哪个差异化方案能改变结果？ |
| 惯性 | 因为一直这样做就继续、忽略新信息 | 如果今天从零开始，我还会选它吗？ |

记录触发事件、当下情绪、自动化叙事和可能造成的代价。不要把扫描结果写成对人的诊断。

## C. 方案生成

至少生成以下类别中的三项，并删除明显重复项：

1. 维持现状或暂缓。
2. 直接执行原始方案。
3. 降低规模/范围的试验。
4. 组合两个看似冲突的选项。
5. 委托、外包或请专家协助。
6. 彻底改变问题定义后再做。

对每个方案写：

```text
方案：
它解决的根因：
短期收益：
长期收益：
机会成本：
最坏情况：
可逆性：高 / 中 / 低
需要验证的关键假设：
```

用“预演失败”提前想象方案失败的原因；用“长期视角”检查它是否符合一年或更长时间后的目标。

## D. 评估矩阵

先让用户确认指标；若用户没有指标，可根据目标提出候选指标并标注为假设。

| 指标 | 权重 | 方案 A | 方案 B | 方案 C | 证据/不确定性 |
| --- | ---: | ---: | ---: | ---: | --- |
| 目标匹配 |  |  |  |  |  |
| 下行风险 |  |  |  |  |  |
| 可逆性/退出 |  |  |  |  |  |
| 时间与资源 |  |  |  |  |  |
| 学习价值/期权价值 |  |  |  |  |  |

不要把主观分数伪装成精确预测。用区间、置信度或“待验证”表达未知数。

### 信息质量

- **高保真**：接近源头的原始数据、亲身观察、实际试用、原始合同/指标、当事人一手说明。
- **高专业**：处理过相似问题且能说明适用边界的专家；先带着自己的初步研究和具体问题去咨询。
- **边际价值**：每轮新增信息是否仍可能改变选择？如果不会，设定截止时间并行动。

## E. 反转性与安全边际

```text
决定的后果：低 / 中 / 高
反悔成本：低 / 中 / 高
可逆性：高 / 中 / 低
最坏情况：
可承受上限：
缓冲（钱/时间/精力/容量）：
退出或止损触发器：
回退方案：
复核日期：
```

“先子弹后炮弹”适合探索性决策：先投入可承受的小成本，观察真实信号，再决定是否升级。它不等于永远小步试错；当证据达到预设阈值，应按计划扩大投入。

涉及辞职、创业或个人财务时，不能只看“有几个月存款”：核对每月必要支出、债务、保险、家属责任、现有收入/付费信号、合同与知识产权限制，以及可回退的工作路径。任何预算比例、收入阈值或试验期限都应标为待确认假设，由用户结合自身情况设定。

对有明显疲劳、情绪激动或资源耗尽风险的场景，提前写停止时间、返程规则或权限上限，不在临界状态临时改规则。

## F. 决策日志

```text
日期：
问题定义：
我当时知道的事实：
我采用的假设：
我不知道的关键事项：
考虑过的选项：
选择与理由：
信心（0-100）：
预期出现的信号及时间：
安全边际/退出条件：
复核日期：
```

复盘时回答：

- 哪些判断在当时的信息下是合理的？
- 哪些是假设错误、执行错误或运气因素？
- 是否出现了本能接管的证据？
- 哪个信息最有价值，哪个信息只是噪音？
- 下次应改变问题定义、标准、阈值还是行动节奏？

不要因为结果好就证明过程正确，也不要因为结果坏就证明过程错误。复盘的目标是改进可重复的判断过程。
